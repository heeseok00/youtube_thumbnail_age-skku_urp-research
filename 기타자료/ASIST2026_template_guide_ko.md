- [ ] 저자란 비워두기 (익명 심사)
- [ ] Abstract 150단어 이하
- [ ] Keywords 5개 이하, 세미콜론 구분
- [ ] 섹션 번호 없음
- [ ] 표 캡션: 표 아래 / 그림 캡션: 그림 아래
- [ ] "Fig." 대신 "Figure" 표기
- [ ] 인용: APA 6판 or 7판
- [ ] References: 알파벳순 (저자 성 기준)
- [ ] Generative AI Use 섹션 포함 (표준 문구 사용)
- [ ] 포스터 본문 2페이지 이내 (Generative AI Use / Acknowledgments / References 미포함)
- [ ] US Letter 사이즈 PDF 제출
- [ ] 이미지 해상도 300dpi 이상
- [ ] 각주·미주 사용 금지

## 1. 일반 개요 (섹션 순서)

```
제목 (Title Style)
저자 섹션 ← 첫 제출 시 반드시 비워둠
Abstract
Keywords
Introduction
[본문 Sections]
  Sub-sections
  Sub-subsubsections
Tables & Figures
Conclusion
─────────────────────── (이하 페이지 카운트 미포함)
Generative AI Use

References
```

## 2. 제목 및 저자

- 제목·저자·소속은 페이지 전체 너비 **단일 컬럼** (6.5인치 / 16.51cm)으로 배치
- 스타일: 제목 → Title Style / 저자 → Author Name Style / 소속·이메일 → Author Affiliation and Email Style
- 저자 정보는 **표 셀** 안에 입력

### ⚠️ 저자 익명 처리 (IMPORTANT)

> **All papers and posters (not panels) submitted for review must be author-anonymized.**
> **Do NOT complete the author section for your first submission.**
> **You will add author names when you submit your final version if accepted for presentation.**

Accept 후 최종본 저자 표기 형식:

| Last name, first name (1st Author) | Affiliation, Country \| email |
|------------------------------------|-------------------------------|
| Last name, first name (2nd Author) | Affiliation, Country \| email |
| Last name, first name (3rd Author) | Affiliation, Country \| email |

---

## 3. Abstract

- **최대 150단어** (필수)
- 포함 내용: 문제 → 접근 방법 → 결과 → 함의
- 해당 분야에 대한 본 논문의 기여를 명확히 서술

---

## 4. Keywords

- **최대 5개** (필수)
- **세미콜론(;)으로 구분**
- 심사자 배정 및 색인에 활용

## 5. 페이지 형식

| 항목 | 규정 |
|------|------|
| 용지 | **US Letter** (A4 아님) |
| 컬럼 | 단일 컬럼 (싱글 컬럼) |
| 정렬 | 오른쪽 여백 정렬 (justified) |
| 본문 폰트 | Times New Roman 10pt (Normal Style) |
| 마침표 후 띄어쓰기 | **1칸** (2칸 아님) |

## 6. 섹션 제목 스타일

| 단계 | 스타일 | 예시 |
|------|--------|------|
| 섹션 (1단계) | Arial 10pt **bold**, 전체 **대문자** | `METHODOLOGY` |
| Sub-section (2단계) | Arial 10pt **bold**, 첫 글자 대문자 | `Data Collection` |
| Sub-subsubsection (3단계) | Arial 10pt *italic*, 첫 글자 대문자 | *Feature extraction* |

- **섹션 번호 없음**
- the / of 등 소사는 소문자 (단, 첫 단어는 대문자)
- **최대 3단계** 제목 구조 허용

---

## 7. 표 & 그림

- 표: **"Tabletext" Style** 사용
- 캡션 위치: 표/그림 **아래**에 배치
- 캡션 형식: `Table 1. 캡션내용` / `Figure 1. 캡션내용`
- **"Fig." 약어 사용 금지** → 반드시 "Figure"로 표기
- **자동 번호 매기기 금지** → 수동으로 번호 기재
- 이미지 해상도: **300dpi 이상**, 흑백 인쇄 시에도 판독 가능
- 가능하면 본문에서 해당 표/그림을 언급하는 단락 끝에 배치

---

## 8. 본문 내 인용 (In-Text Citations)

- **APA 6판 또는 7판** 형식
- 모든 본문 인용 → References에 포함 필수 (역도 마찬가지)
- 공개 접근 가능한 출판물만 인용 가능
- 사유 정보(proprietary information) 인용 불가
- 비공개 커뮤니케이션: `[홍길동, personal communication]`으로 본문 표기
- **각주·미주 사용 불가**

---

## 9. CONCLUSION

- ASIS&T 독자를 대상으로 작성
- "무엇을 했는가"를 명확히 서술 (계획이 아닌 **완료된 작업** 기준)
- 기존 연구와의 **차별성** 설명
- 논문이 해당 분야에 기여하는 **고유한 가치** (*the unique contribution that your work makes to the field*) 명시
- 독자가 논문을 읽고 얻는 것이 무엇인지 고려

## 10. GENERATIVE AI USE *(페이지 카운트 미포함)*

- AI를 저자로 표기 불가
- 민감 정보를 AI에 업로드하지 말 것
- 아래 두 표준 문구 중 하나를 선택하여 그대로 사용:

**미사용 시:**
> "We confirm that we did not use generative AI tools/services to author this submission."

**사용 시:**
> "We employed [generative AI tool/service] for the following purpose(s): (목적 나열). We evaluated the output by (검증 방법 설명). The authors assume all responsibility for the content of this submission."

## 11. AUTHOR ATTRIBUTION *(Accept된 논문에만 요청)*

CRediT (Contributor Roles Taxonomy) 방식으로 역할 기술.

**14개 CRediT 역할:**
conceptualization / data curation / formal analysis / funding acquisition / investigation / methodology / project administration / resources / software / supervision / validation / visualization / writing – original draft / writing – review and editing

**표기 예시:**
> First Author: conceptualization, methodology, data curation, formal analysis, writing – original draft;
> Second Author: data curation, formal analysis, visualization, writing – review and editing;
> Third Author: project administration, funding acquisition, supervision, writing – review and editing.

## 14. 언어·스타일 지침

- **영어** (영국식/캐나다식/미국식 모두 허용, 단 일관성 유지)
- 직설적인 문체, 짧은 문장 구조
- 처음 등장하는 전문 용어는 반드시 설명 (예: "Facial Expression Recognition (FER)")
- 지역 고유 표현 설명 (도시명 언급 시 국가명 포함)
- 문화적 insider 표현, 관용 표현, 말장난 지양
- 날짜·화폐 등 문화 모호 표현 명확히 표기
- **성 중립 언어** 사용 (he/she → they; chairman → chairperson)
- 인명·기관명·지명: 완전한 알파벳 표기

3. 기본 언어 설정 확인
4. 탭 순서를 "Use Document Structure"로 설정

## 18. Word 스타일 적용 방법

1. 템플릿 문서의 **1~5페이지 삭제**, 6페이지(빈 페이지)부터 시작
2. 본인 논문 내용을 6페이지에 붙여넣기
3. `Home > Styles Pane`에서 스타일 확인
4. 섹션 제목 클릭 → "Section Heading" 스타일 적용
5. 저자명 클릭 → "Author Name" 스타일 적용
6. 표/그림 캡션 클릭 → "Caption (Figure and Table)" 스타일 적용
7. References 텍스트 → "References" 스타일 적용
